# Demo - Execution Protocol

## Welcome to the Documentation Hub

This directory contains all the documentation for the Execution Protocol demo.

## Quick Start

The demo consists of:

- **docs/** - Documentation by system (terminal, chat, combat, etc.)
- **dialogues/** - Dialogue files for NPCs
- **tasks/** - Implementation tasks with dependencies

## Directory Structure

```
docs/demo/
├── docs/           # System documentation
├── dialogues/      # NPC dialogues
└── tasks/         # Implementation tasks
```
