# OmniTerm - Home 🏠

Bem-vindo à documentação modular do **OmniTerm**, a camada de linha de comando base (Shell/CUI) da suíte Omni-System.  
Navegue pelos tópicos abaixo para acessar os manuais:

- [[Instalação do Nó Terminal]]: Saiba como importar o painel do CUI na cena, integrar ao chat e alterar prompts de "user@local".
- [[Criação de Comandos Básicos]]: O guia prático passo a passo de como estruturar executáveis (`CommandBase`) que processam texto dentro da linha de comando e interagem com a UI.
- [[Arquitetura e Utilitários de Terminal]]: Guia técnico de navegação de comandos, preenchimento assíncrono (autocomplete c/ fantasma), buffer de histórico, etc.
- [[Integrando Terminal num RPG]]: Arquitetura recomendada para que você desacople o Terminal da Engine do seu GameState para evitar um código altamente entrelaçado, usando o OmniTerm apenas como entrada/saída visual.
- [[Localização]]: Chaves internas e boas práticas para traduzir seu terminal.
